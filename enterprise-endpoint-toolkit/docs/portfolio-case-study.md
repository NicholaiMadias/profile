# Portfolio case study: Enterprise Endpoint Automation Toolkit

**Problem:** Endpoint teams often maintain disconnected scripts for inventory, monitoring, and reporting.

**Approach:** A modular reference toolkit combines PowerShell collection, Python reporting, Microsoft Graph access, Workspace ONE examples, and reusable AI prompt templates.

**Engineering considerations:** Least privilege, pagination, missing values, error propagation, tenant-specific authentication, sensitive inventory, and CI validation.

**Evidence:** Source code and documentation in this repository. No claims of production deployment, fleet size, time savings, or compliance improvement are made without measurement.

**Potential resume entry:** Built a public portfolio reference toolkit combining modular PowerShell endpoint inventory and service monitoring, Microsoft Graph and Workspace ONE API examples, Python visualization, and reusable AI engineering prompts.
