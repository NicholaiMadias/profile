# Security Policy

## Supported versions

The latest commit on `main` is supported. Older commits and untagged builds do
not receive security updates.

## Reporting a vulnerability

Please report vulnerabilities privately using **Report a vulnerability** on
the repository's **Security** tab. Do not open a public issue or include
credentials, personal data, or exploit details in a public discussion.

Maintainers aim to acknowledge reports within five business days and will
provide updates while investigating. Please include the affected version,
impact, and steps to reproduce using a non-sensitive test case. We will
coordinate any fix and disclosure with the reporter.
